# hicleanarch-social

Reference code for the social network course on hicleanarch.com: a news feed with recommendations, built as a cloud-native modular monolith with clean architecture on .NET, then split into microservices. The social graph lives in a graph database (Neo4j locally; Amazon Neptune with openCypher on AWS).

Each Builder lesson is a tag. Tags are append-only: fixes found later land as new commits and are carried into the next tag.

The code is under construction.
